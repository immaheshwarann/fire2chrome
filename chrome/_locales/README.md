# _locales/ — Internationalisation Strings

This directory must contain the `messages.json` locale files.
Extract them from the `.xpi` archive:

```
_locales/
└── en/
    └── messages.json
```

Additional locale directories (e.g. `de/`, `fr/`, `ja/`, …) may also be present
in the original package and can be copied here as-is.
